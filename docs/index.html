LRLab

東京科学大学 LRLab / 奥村・船越研究室

LRLab は、ことばを理解し、人と協調する知的システムの実現を目指す研究室です。自然言語処理、マルチモーダル対話システム、知識処理、言語資源の構築と評価を中心に、基礎研究から応用研究まで幅広く取り組んでいます。
