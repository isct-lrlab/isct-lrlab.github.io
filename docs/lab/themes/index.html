研究テーマの選び方

基本方針

各人の興味に基づいて，自分でテーマを探す努力をしてもらいます．

テーマの提案はしますが，こちらが用意したテーマを強制することはありません． ゼミで研究テーマ案について発表してフィードバックをもらったり，教員と個別に相談をしながら，テーマを決定していきます．

研究可能なテーマ

自然言語処理，対話システムあるいはヒューマンマシンインタラクション（マシン=コンピュータ／エージェ ント／ロボット）に関わる内容であれば指導できます．

対話ロボットの発話タイミングの決定や，ユーザの内部状態（感情・意欲等）の音声・画像からの推定など，非言語情報処理関連のテーマでも取り組めます．

研究室で取り組んでいるテーマについては，研究テーマ を御覧ください．
